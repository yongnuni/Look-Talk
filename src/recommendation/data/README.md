# Korean Chosung Word Data

`chosung_words.json.gz` is derivative word-frequency data generated by the
Look-Talk project from `wordfreq` 3.1.1. It contains NFC-normalized Korean
words, their initial-consonant sequences, source frequencies, and filtered
frequency ranks. It is input data for Look-Talk's later Trie-building stage.

## Look-Talk transformation

Look-Talk iterates the Korean `best` wordlist in its original descending
frequency order, normalizes each token to NFC, keeps only words composed
entirely of precomposed Hangul syllables (`U+AC00` through `U+D7A3`), preserves
one-syllable words, removes normalized duplicates after their first occurrence,
and adds the Chosung sequence and filtered rank. The deterministic build command
is:

```powershell
python -m scripts.build_chosung_dictionary
```

The generated JSON includes its source version, filtering rules, sorting rule,
license, and attribution. It contains no generation timestamp.
